# Bundled Slate Trust fonts

These WOFF2 assets are Latin subsets of the Inter variable family (Google Fonts CSS v20) and Fraunces variable family (Google Fonts CSS v38). They are served locally by the client; the application does not request Google Fonts at runtime.

Both families are licensed under the SIL Open Font License 1.1. The complete license texts are included as `Inter-OFL.txt` and `Fraunces-OFL.txt` alongside the font files.

- Inter: Copyright 2020 The Inter Project Authors. Upstream: https://github.com/rsms/inter
- Fraunces: Copyright 2018 The Fraunces Project Authors. Upstream: https://github.com/undercasetype/Fraunces

These files include the Latin character subset used by the current interface. Characters outside that subset use the system fallback stack declared in the Slate Trust tokens.
