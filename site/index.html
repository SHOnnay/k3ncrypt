Download · Security · Self-host · Source code

Security

K3NCRYPT is designed so a relay carries encrypted data rather than message plaintext. Device changes require explicit approval and current trust. Review the privacy guide for the service’s limits and your responsibilities.

Download

Beta release packages are prepared for Android and desktop hosts. Until signed packages are published, run the source build and follow the release guide.

Self-host

Run your own relay and optional private-network nodes. Site bridges require explicit host-and-service route authorizations; they do not expose a LAN automatically.

K3NCRYPT is beta software. Verify important contacts and keep recovery material offline.
