## Authority finding

BLOCKED — There is no single reconciled normative connectivity specification in the current closure branch or the inspected origin/main snapshot. The closure branch contains review and implementation evidence, while several documents it references live only on sibling branches. A document's own “accepted” or “approved” label describes that branch's decision; it does not make the document part of another branch's governing baseline.

The product code in the closure branch remains relay-only. A relay-path adapter exists there, but the separate DeliveryCoordinator implementation is on the unmerged connectivity/delivery-coordinator ref. Neither that ref nor the other specification branches were merged or copied into this worktree. origin/main at the inspected snapshot has no tracked docs/connectivity files and predates the closure changes.
